# hk-racing-odds

自動收集香港賽馬會（HKJC）本地賽事嘅公開原始數據。只讀取公開網頁，唔會登入、唔會投注，亦唔會做任何篩選或者分析。

## 數據檔案（UTF-8 CSV）
記錄到嘅數據放喺另一個私人 repo，唔喺呢度公開。workflow 會用 `DATA_TOKEN` secret 將私人 repo clone 去 `data/`，記錄完再 push 返去。以下係檔案同欄位說明。

### `2026-27季_賠率記錄.csv`（每個馬季一個檔）
欄位：記錄時間HKT, 日期, 場地, 場次, 開跑時間, 距開跑分鐘, 時間點類別, 馬號, 馬名, 檔位, 負磅, 騎師, 練馬師, 獨贏賠率, 位置賠率, 獨贏彩池投注額, 位置彩池投注額

| 時間點類別 | 記錄時間（香港時間） |
|---|---|
| 隔夜 | 賽馬日前一日 22:00（未開賣 23:00 再試） |
| 早段 | 賽馬日 10:50 |
| 開跑前60／開跑前30／開跑前10 | 每場開跑前約 60／30／10 分鐘 |
| 走勢 | 最後一場開跑後約 15 分鐘，讀獨贏賠率走勢頁，每個時間點一行 |

- 騎師名已去咗減磅括號。退出馬照記，賠率留空。
- 「距開跑分鐘」= 開跑時間 − 記錄時間（走勢頁可以係負數）。走勢頁只有最後一個時間點有位置賠率。
- 彩池投注額欄：格式未驗證，讀唔到就留空。

### `2026-27季_排位表.csv`（賽馬日 10:50 後記錄，每匹馬一行）
欄位：記錄時間HKT, 日期, 場地, 場次, 賽事名稱, 開跑時間, 跑道, 賽道, 路程, 場地狀況, 班次, 評分範圍, 獎金, 馬匹ID, 馬匹編號, 6次近績, 馬名, 烙號, 負磅, 騎師, 可能超磅, 檔位, 練馬師, 國際評分, 評分, 評分+/-, 排位體重, 排位體重+/-, 最佳時間, 馬齡, 分齡讓磅, 性別, 今季獎金, 優先參賽次序, 上賽距今日數, 配備, 馬主, 父系, 母系, 進口類別
- 馬匹欄位係排位表原文（騎師保留減磅括號）。

### `馬匹往績.csv`（所有馬季共用，同排位表一齊記錄）
欄位：記錄時間HKT, 馬匹ID, 馬名, 往績場次編號, 往績名次, 往績日期, 馬場/跑道/賽道, 途程, 往績場地狀況, 賽事班次, 往績檔位, 往績評分, 練馬師, 騎師, 頭馬距離, 獨贏賠率, 實際負磅, 沿途走位, 完成時間, 排位體重, 配備
- 來自馬匹資料頁「所有往績」。只記馬場以「沙田」或「跑馬地」開頭嘅香港賽績。同一匹馬同一場只記一次。

### `2026-27季_賽果.csv`（最後一場走勢記錄後讀取）
欄位：記錄時間HKT, 日期, 場地, 場次, 賽事名稱, 開跑時間, 跑道, 賽道, 路程, 場地狀況, 班次, 評分範圍, 獎金, 名次, 馬號, 馬名, 騎師, 練馬師, 實際負磅, 排位體重, 檔位, 頭馬距離, 沿途走位, 完成時間, 獨贏賠率
- 賽果頁冇開跑時間，呢欄留空。

### `2026-27季_派彩.csv`
欄位：記錄時間HKT, 日期, 場地, 場次, 彩池, 勝出組合, 派彩, 單位（一般「每$10」）

### `記錄日誌.csv`
欄位：記錄時間, 檔案, 場次, 問題 —— 只記錄有問題嘅情況（例如漏賠率、馬匹數目唔對、讀唔到欄位）。

### `state/`
程式自己用嘅工作檔。

## 運作
- GitHub Actions 定時執行；GitHub 定時經常延遲或者漏咗，所以只要有一次執行，程式就會檢查今日同聽日有冇賽事：有就留低等時間點（每次最多 5 個鐘），然後自動觸發下一次執行，由賽馬日前一日一直接力到記錄完賽果。每次記錄完即刻 push。
- 每次讀網頁之間停 1–2 秒。唔保存網頁原檔。
- 記錄失敗時 workflow 會顯示失敗。
- 暫停：Actions → 記錄賠率 → 右上「⋯」→ Disable workflow。
